# Lista de assets por arquivo

Regras gerais:
- **Chãos**: vistos bem de cima (90°), cada quadrado emenda nele mesmo (direita com esquerda, cima com baixo), sem sombra forte, cada um cobrindo ~2 × 2 m.
- **Objetos e plantas**: vista de cima a 45°–50° (igual aos personagens), PNG com fundo transparente, sem sombra no chão, com espaço vazio entre um item e outro.
- **Grade**: cada arquivo é uma grade. A ordem é da esquerda para a direita e de cima para baixo, como numerada.
